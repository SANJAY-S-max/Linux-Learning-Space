# 🧠 Core Concept of This Level

```
You act as CLIENT
Service runs on localhost:30000

Flow:
You → send password → Service → returns next password
```

---

# ⚙️ PRIMARY TOOL: `nc` (Netcat)

---

## 🔹 What is `nc`?

```
Netcat = "Swiss Army Knife of Networking"

Used for:
✔ Connect to ports
✔ Send/receive raw data
✔ Debug network services
```

---

## 🔹 Basic Command

```
nc localhost 30000
```

---

## 🔍 Breakdown

|Part|Meaning|
|---|---|
|nc|netcat tool|
|localhost|target system|
|30000|port|

---

## 🔹 Usage Flow

```
nc localhost 30000
# paste password
# press Enter
```

---

## 🔹 Output

```
Correct → returns bandit15 password
Wrong → no useful output
```

---

## 🔹 One-Line Automation

```
cat /etc/bandit_pass/bandit14 | nc localhost 30000
```

---

## 🔍 Pipe Explanation

```
| (pipe):
Left output → Right input

cat → prints password
nc → sends it to server
```

---

## 🔹 Purpose

```
Old tool for connecting to TCP services
```

---

```
✔ Opens connection

✔ Shows raw response
```

## ⚠️ Limitations

```

❌ Mostly deprecated
❌ Replaced by nc / ssh
```
