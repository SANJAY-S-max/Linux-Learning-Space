## 🎯 Goal

Password is stored in a **hidden file** inside the `inhere` directory.

## 🧠 Concept: Hidden Files

```
Hidden files start with a dot (.)
Example:
.hidden
```

- Normal `ls` → does NOT show hidden files
- `ls -a` → shows ALL files (including hidden)

## ⚙️ Commands Used

```
ls
cd inhere
ls -a
cat .hidden
```
