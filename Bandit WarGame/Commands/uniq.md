### 🎯 Purpose

```
Filter duplicate or unique lines
```

---

### 🧾 Syntax

```
uniq [option]
```

---

### 🔹 Unique lines only

```
uniq -u
```

---

### 🔍 Example

```
sort data.txt | uniq -u
```

---

### ⚡ Key Points

```
Works only on sorted data
-u → shows lines that appear once
```

## 🧾 One-Line Summary

```
Use sort with uniq -u and pipe to find unique lines
```
