### 🎯 Purpose

```
Sort lines in a file (alphabetically by default)
```

---

### 🧾 Syntax

```
sort filename
```

---

### 🔍 Example

```
sort data.txt
```

---

### ⚡ Key Points

```
Rearranges lines
Required before using uniq
```

## 🧾 One-Line Summary

```
Use sort with uniq -u and pipe to find unique lines
```
