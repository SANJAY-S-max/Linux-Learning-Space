## 🎯 Purpose

```
Archive multiple files into one file
```

## ⚙️ Syntax

```
tar [options] file.tar
```

## 🔹 Extract Example

```
tar -xf file.tar
```

## ⚡ Key Points

```
Used for archiving
-x → extract
-f → file
```

## 🔹 List contents

```
tar -tf data.tar
```

---

## 🔹 Flags

|Flag|Meaning|
|---|---|
|`-x`|extract|
|`-t`|list|
|`-f`|file|

---

## 🔹 Behavior

```
- Extracts files
- Does NOT delete archive
```
