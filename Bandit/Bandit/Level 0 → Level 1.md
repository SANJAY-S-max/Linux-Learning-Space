
# 🎯 Goal
Find the password stored in a file called "readme" in the home directory

## 🧪 Steps I Did
```bash
ls
cat readme
```


## 💡 Explanation

- Used `ls` to list files in the current directory
- Found a file named "readme"
- Used `cat` to read the file content
- The output is the password for the next level

## 🧠 Key Takeaways

- `ls` is used to discover files
- `cat` is used to read file contents
