# Linux-Learning-Space 🐧🔒

Welcome to the **Linux-Learning-Space**! This repository serves as a personal knowledge base and write-up collection for mastering Linux and basic cybersecurity concepts. A significant portion of this repository focuses on completing the famous **OverTheWire: Bandit Wargame**.

## 📁 Repository Structure

The repository is organized under the `Bandit WarGame/` directory, which is divided into three main sections:

### 🎮 1. Bandit Writeups (`Bandit/`)
Detailed walkthroughs and solutions for the **OverTheWire Bandit** challenges. Currently includes levels 0 through 15:
- `Level 0 → Level 1.md`
- `Level 1 → Level 2.md`
- ... up to `Level 14 → Level 15.md`

These writeups explain the thought process, the commands used, and how the password for the next level was obtained.

### 🛠️ 2. Linux Commands Reference (`Commands/`)
A collection of notes and cheat sheets on essential Linux commands learned along the journey. These files serve as a quick reference for syntax and usage. 
Some of the covered commands include:
- **File Management & Navigation:** `cd`, `ls`, `cp`, `mv`, `rm`, `find`, `file`, `mkdir`, `mktemp`
- **Text Processing & Searching:** `cat`, `grep`, `strings`, `sort`, `uniq`, `tr`
- **Permissions:** `chmod`, `whoami`
- **Networking & SSH:** `ssh`, `scp`, `nc` (Netcat), `nmap`
- **Compression & Archiving:** `tar`, `gzip`, `bzip2`
- **Data Encoding:** `base64`, `xxd`
- **Concepts:** Piping (`|`), `nano`

### 🧠 3. Networking & General Concepts (`Concepts/`)
Explanations of fundamental networking and computing concepts that are crucial for understanding system administration and security:
- `Localhost.md`
- `Port.md`
- `TCP.md`

## 🚀 About the Bandit Wargame

The [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) wargame is aimed at beginners. It teaches the basics of Linux command line operations and essential security concepts. By playing through this wargame, you learn how to navigate the file system, manage permissions, manipulate text, and establish secure connections.

## 📌 Getting Started

Feel free to browse through the writeups if you get stuck on a Bandit level, or use the `Commands/` section as a quick reference guide. 

> **Disclaimer:** If you are playing the Bandit Wargame yourself, it is highly recommended to try solving the levels on your own before looking at the writeups!
